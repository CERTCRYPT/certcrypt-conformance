# SHA3-256 / SHAKE-256 come from the Python standard library (hashlib); no pin
# needed. These cover Ed25519 (RFC 8032 deterministic), ML-DSA-65 (FIPS 204
# deterministic variant), and ECDSA P-256 (RFC 6979 deterministic, via
# python-ecdsa — `cryptography`'s ECDSA uses a random nonce, which would make
# fixtures non-reproducible). Every signature
# scheme used here is deterministic, so any independent generator reproduces the
# same committed fixtures, and the P-256 component is byte-identical to any
# RFC 6979 signer with H = SHA3-256 (the `ecdsa-p256-deterministic` family).
