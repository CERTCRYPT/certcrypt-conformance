# Working in this repository

This repository is public. Everything committed to it — code, comments,
docstrings, tests, documentation, file names and commit messages — can be read
by anyone, and once published it cannot be recalled.

Write for a reader who has only this repository and the published
specifications:

- Describe what the code does and why. Do not narrate how it came to be
  ("it used to…", "now it…", "after the change…").
- Do not reference anything that reader cannot see: non-public documents,
  reviews or audits and their identifiers, internal processes, tasks, decisions
  or discussions, non-public repositories, hosts, environments, people or test
  fixtures.
- Do not describe how the service is operated or deployed.
- Write commit messages in English, under the same rules.

Commits and pushes are checked automatically against these rules. Never bypass
the checks (`--no-verify` or similar). If a check refuses legitimate text,
report it instead of working around it.
